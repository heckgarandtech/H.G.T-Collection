# H.G.T-Collection
H.G.T Collection - Versão 1.0 (in dev) 

Estou lançando hoje a primeira versão (ainda em desenvolvimento) do H.G.T Collection, um projeto que estou desenvolvendo.
Essa coleção tem como objetivo reunir, em um só lugar, tutoriais, ferramentas, documentos, drivers e recursos extras diversos...

 O que tem nessa versão 1.0 (in dev)?
Interface simples via terminal, com navegação por número

Organização inicial das seções principais

Acesso rápido à pasta raiz do programa

Estrutura pronta para expansão (tutoriais, ferramentas, etc.)

(Pack de ferramentas, documentos e firmwares)

IMPORTANTE: Como está in dev, então esperem bugs, furos e ideias ainda em construção.
Mas justamente por isso, quero o feedback de vocês. Sugestões, críticas, elogios...

Como usar?
Acesse o link do mediafire () e baixe o .rar, extraia tudo em uma pasta (Download por exemplo) e execute o arquivo dentro da pasta.

Use o atalho 5 para abrir o diretorio raiz e acessar o conteudo (caso não use as opção de mostrar itens ocultos)

Tudo escrito em .bat, projeto open source
